Finanssi2 test pages

Components rendered with a fake login and a fake backend. Not part of the app build.

  • Chat – logged-in front page with chat history loaded lazily (?count=N, default 100), simulated incoming messages and websocket disconnects
  • Game list – one game for each status and role, with a fake backend that applies create, join, leave, settings, start, end game and delete; add ?debug for debug games
  • Game room – mocked board and running game, with Maija on square 40 where she may build and buy before rolling; ?afterRoll for the turn after rolling, ?turn=olli for another player's turn, ?news=FL-19 or ?afterRoll&tip=PV-31 for other face-up cards, ?finished for results, ?debug for debug controls
  • Game room with app layout – the same preview inside the app container, with the top menu bar and a viewport-sized layout
